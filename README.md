# Python GUI Calculator

A simple calculator app built with Python's Tkinter library.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Decimal point support
- Clear (C) button to reset the display
- Error handling (e.g. dividing by zero shows "Error" instead of crashing)
- Keyboard input support (type numbers/operators, press Enter to calculate)
- Sound feedback on button clicks

## How to Run

1. Make sure you have Python installed.
2. Clone this repository:

git clone
https://github.com/Jamalyusufope/python-GUI-calculator.git

3. Run the script

python calculator.py
## Built With

- Python
- Tkinter (GUI)
- winsound (click sound effects)
